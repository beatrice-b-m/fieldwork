# Fieldwork 0.2.1

Fieldwork 0.2.1 is a small maintenance release. It fixes a mismatch between live
and saved `value_patterns` results and replaces most wording and layout tests with
tests that recompute analyses independently. Python 3.11–3.14 remains supported;
pandas and NumPy remain the only required runtime dependencies. Saved-result
formats are unchanged from 0.2.0.

## Fixes

- `value_patterns` string summaries (`formats`, `lengths`, `prefixes`) are lists
  of `[value, count]` pairs in memory, as they already were once saved.
  Previously they were tuples until a JSON round trip, so a live result rendered
  its HTML differently from its own saved export and `to_dict()` did not equal
  the saved payload. Code that indexes these pairs is unaffected; code that
  compares them to tuples should compare to lists.

## Reliability

The test suite now checks analytical behavior rather than output wording and
docstring layout:

- independent recomputation of levels, census prefixes and dependency discovery
  (accuracy, exactness, populations, repeated support, exceptions) on random
  frames with every native missing-value spelling, composite keys, contexts and
  scopes;
- hand-computed pair relations and Cramér's V, census options as properties,
  value-pattern measurements and comparisons of differing deliveries;
- the same evidence for categorical, nullable, pyarrow-backed, tz-aware and
  float32 columns as for their object equivalents, and for any row order;
- shared rendering contracts for every result kind and output format, and a
  50,000-row smoke test.

No other analysis or output changed.
