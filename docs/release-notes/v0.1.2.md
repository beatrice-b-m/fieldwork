# Fieldwork 0.1.2

Fieldwork 0.1.2 makes saved evidence reports easier to navigate and interpret,
especially for wide tables and smaller viewports. Python 3.11–3.14 remains
supported; pandas and NumPy remain the only required runtime dependencies.

## Changes since 0.1.1

- The grain HTML matrix now places features in rows and candidate keys in
  columns, with sticky headings, feature search, candidate filtering, and a
  bounded scrolling panel. Cells select their placement evidence. The static
  SVG matrix uses the same orientation with complete wrapped labels.
- Discovery HTML reports add independent text search, pattern and exception-row
  filters for findings, visible counts, and expand/collapse controls. Evidence
  links reveal and focus their targets, including after a direct-link reload.
- Reports distinguish search/retention coverage, display limits, empty saved
  results, and filters with no matches. Full overview visualization data adds
  `section_coverage`, preserving each section's work bounds.
- Source examples show saved/total position counts and explain source-order
  sampling. Findings provide Python inspection guidance; comparisons explain
  percentage-point changes and direct readers to their before/after sources.
- Foundation views add figure scaling, reset controls, selection feedback,
  linked placement evidence, and keyboard operation. Map-only and SVG-scale
  controls are disabled for the native HTML matrix.
- Responsive layouts wrap long controls and stack key/value evidence on narrow
  screens. Wide figures, matrices, and census tables scroll locally. Long
  joint-count axis labels wrap within the SVG instead of being clipped.
- Plaintext and SVG outputs clarify sample and per-list omission counts.
  Empty HTML collections no longer trigger script errors.
- Updated examples and an optional browser qualification harness cover wide
  tables, long labels, empty and limited reports, multiple viewports and scales,
  matrix scrolling, keyboard selection, and evidence navigation.

## Compatibility and interpretation

Public call signatures, analytical measurements, finding IDs, source selectors,
and saved-result schemas are unchanged (discovery 1.0; foundation 0.3).
`section_coverage` is additive presentation data, not a new analytical schema.
HTML structure, matrix orientation, and presentation wording intentionally change.
Regenerate previously saved HTML reports to use the new controls.

Search covers only records included by `max_findings`; it cannot recover omitted
analytical work or fetch source rows. HTML remains an offline snapshot. Native
disclosures remain readable without JavaScript; enhanced controls require it.
Topology projection still removes quantities and source positions before export,
while structural labels remain potentially identifying.

Browser qualification used Chromium with 16 reports at five viewport widths,
including 20,000 rows × 66 columns and many candidate keys. Figure scaling and
layout zoom were exercised from 50% to 200% and 75% to 200%, respectively.
This does not constitute a full screen-reader or cross-browser audit. Very large
unbounded reports still create large documents, and many candidate columns can
require filtering or horizontal scrolling.
