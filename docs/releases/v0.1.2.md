## Output and viewport qualification

The [output UX review](../evaluation/output-ux.md) records the browser fixtures,
results and screenshots. Sixteen reports passed at five viewport widths
(375, 600, 768, 1280 and 1920 pixels), covering 80 combinations in Chromium
151.0.7922.34. Checks included SVG scales from 50% to 200%, layout zoom at
75%, 125% and 200%, and a wide grain analysis with 20,000 rows, 66 columns and
18 candidate keys. Long and Unicode labels, empty reports, display limits,
keyboard controls, filters and evidence links were exercised. There was no page
overflow, clipped SVG labeling, script error or external report request.

The grain matrix now uses features as rows and candidate keys as columns, with
sticky labels, local scrolling and filters. Existing saved reports must be
rendered again to acquire the new controls; rendering cannot restore evidence
excluded from the saved analysis. See [output usage and boundaries](../output-ux.md).
