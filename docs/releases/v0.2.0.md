## Scope

This release implements steps 1–3 of the
[review remediation plan](https://github.com/beatrice-b-m/fieldwork/blob/v0.2.0/temp-docs/review-remediation-plan.md):
verified bug fixes, a ranked overview of investigation leads, vectorized source
fingerprints, bounded grain-view positions, and removal of the compact export and
duplicate `exact_grain`. It intentionally breaks saved-result compatibility with
0.1.x (see the release notes). Steps 4 (test-suite rebalancing) and 5 (architecture
simplification) remain planned.
