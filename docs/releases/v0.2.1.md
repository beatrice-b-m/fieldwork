## Scope

This release contains step 4 of the
[review remediation plan](https://github.com/beatrice-b-m/fieldwork/blob/v0.2.1/temp-docs/review-remediation-plan.md):
a test suite rebalanced around independent oracles, property tests and
structural rendering contracts, which found one bug. `value_patterns` string
summaries are now lists in memory, as they already were once saved. Step 5
(architecture simplification) remains planned.
